# 随机三叉/四叉路网

纯三叉网络现在统一走两车道模板：`type=t`、`t_probability=1` 或全部路口显式指定为 t 时，`random-grid` 自动转入 `random_t_network.py`。下文三车道编码只适用于混合路网；纯三叉使用说明见 `PURE_T_NETWORK.md`。

生成入口：`toolkit.py random-grid --config CONFIG --out EMPTY_DIRECTORY`。
先确定全部路口类型与缺失方向，再生成全四叉网格并删除指定道路，重建三叉内部连接与路口铺面。

```json
{
  "name": "random_3x3",
  "rows": 3,
  "columns": 3,
  "seed": 42,
  "t_probability": 0.5
}
```

`t_probability` 为三叉概率，默认 0.5，四叉概率为其补值。可通过 `junction_types` 指定部分或全部路口类型，如 `{"0,0":"t"}`；可通过 `missing_arms` 固定三叉缺失方向，如 `{"0,0":"north"}`。其余三叉在四方向中等概率提议，拒绝使全网不连通的方向组合，保留先确定的路口类型。固定方向无法连通或抽样超过上限会明确报错，不输出断开的地图。seed 保证可复现。

最终方向分布是以全网连通为条件的分布，并非无条件各占 25%。例如一行路网的中间路口不能删除横向连接。未同时保留两端道路的网格接缝会解除双向 road/lane link；相邻路口仍存在的半段道路保留为终端支路，不额外删除该路口的第二个方向。

三车道从进道口左到右（OpenDRIVE -1、-2、-3）：

|删除方向|west|south|east|north|
|---|---|---|---|---|
|north|直、直、右|左、左、右|左、左、直|删除|
|south|左、左、直|删除|直、直、右|左、左、右|
|east|左、左、右|左、左、直|删除|直、直、右|
|west|删除|直、直、右|左、左、右|左、左、直|

出口显式编码为目标道路的 +1、+2、+3 车道，分别对应入口 -1、-2、-3；同一入口的双左转/双直行分别连接不同出口车道。连接由生成器写入 OpenDRIVE junction connection 与内部道路 lane link，不依赖 CARLA 推测。

`audit_experiment_map.py` 检查每条入口车道的真实出口集合与 manifest 完全相符、接缝双向连通、路口图连通。实际物理通行可用 `release_drive_check.py` 测试；这不代表多车冲突与信号配时已经认证。此规则适用于随机生成的三车道路网，旧两车道三叉模板仍保留其两车道规则。

既有 map.xodr 不会因脚本更新自动变化；需要生成到新目录并验证后再替换。美化继续由统一 view.py 自动选择。
