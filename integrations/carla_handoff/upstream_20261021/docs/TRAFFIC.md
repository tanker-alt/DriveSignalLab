# 混合车型与初始净间距

种子职责更新：生成器 --seed（默认 17）只控制本地车队随机；控制器 --tm-seed（默认 17）
在接管信号之前设置 Traffic Manager 种子。CARLA 设置 TM 种子会重置全部灯，运行期禁止重新设置。
车队清单增加 seed_scope=fleet_python_only、tm_seed_source=external_world_owner；
实际 TM 种子见对应实验 controller_config.json。旧清单字段按其原版本解释，不改写。

配置入口是 `evaluation/configs/traffic.json`。用户要求轿车优先，初始权重设为
sedan / suv / truck / bus = 60 / 20 / 15 / 5，可调整权重、类别蓝图白名单及 spawn_gap_m。
权重不必合计 100，程序按总权重归一化。sedan 在此作为普通小型乘用车分组，白名单含轿车、
紧凑型及双门乘用车；用户可按研究所需收窄。配置中的蓝图按服务端实际可用情况筛选。

在 newProject 目录执行（另一个进程已推进世界）：

```powershell
python spawn_junction_traffic.py --vehicles-per-approach 6 --duration-seconds 180
python spawn_junction_traffic.py --traffic-config evaluation/configs/traffic.json --spawn-gap 2.5
```

第二条展示参数覆盖方式，不要同时运行两条命令。`--spawn-gap` 优先于配置中的 spawn_gap_m。
旧 `--queue-spacing` 已移除，它表示原点间距，不能用来表示车尾到车头净间距。
`--vehicle-blueprint vehicle.tesla.model3` 仍支持单一车型对照实验，此时覆盖比例分配。
有明确四轮及以上属性的蓝图才可生成；无轮数属性不会被默认为合格车型。

## 数量、失败与清单

先按总计划车辆数分配类别数量：向下取整，再将余数名额给小数部分最大的类别。
例如 24 辆的初始配置得到 14 辆小型乘用车、5 辆 SUV、4 辆货车、1 辆公交。
这是整轮比例，不承诺每条进口或每个小车队都有相同比例；随后按种子打乱类别顺序，
在各类别可用白名单中选车型。同一生成任务的重试不更换车型。

应生成的类别没有可用蓝图时报错；生成失败或间距不合格会中止整轮并清理已生成车辆，
不会用轿车补足缺失公交，或把缩小后的车队报告为成功。
spawn_manifest 中保存原配置、目标数量、已生成数量、每项任务状态、实测净距、
前车 ID、摆放帧、释放帧和失败原因。已生成数量表示历史创建情况，不等于退出后存活数量。

## 2 米的具体含义

道路中心线沿上游以 0.5 m 采样，车辆包围盒顶点投影到该线，求车身纵向覆盖区间。
后车最前端与前车最后端的区间间隔目标为 2 m，校验容差为 0.05 m。
这是一种沿道路的初始纵向净距，弯道上不同于世界坐标中的最短车身距离；
它也不是 TM 运行中的目标跟车距离或队列连接阈值。真实地图需独立验证采样误差与车辆几何。

CARLA 蓝图不直接提供包围盒，因此每种实际选中车型会短暂生成一个几何测量 actor，
读取包围盒后立即销毁并核验；本项目采集器跳过保留角色名 `junction_geometry_probe`。
探测 actor 仍是服务端 actor，因此这一准备流程应在测试场景中完成，不能用于要求完全无扰动的采集。
每个 actor 创建后立即登记清理责任，不因后续配置失败而遗漏。

正式测试车辆在整队摆放时暂时关闭物理，再逐车恢复并交给 TM；生成器不调用 tick。
只跟随唯一上游道路，遇到分叉/相邻路口停止追溯，最多使用 150 m 的上游路径。
道路不足或无法求解满足容差的净距时明确失败。物理恢复后会落地并开始移动，
所以不能要求之后每帧仍恰好 2 m，也不承诺多个车辆在同一帧释放。

## 评估必须排除准备阶段

原始采集会记录暂时停放的正式车辆，在线 summary 也可能包含准备期停车；它不是纯运行期指标。
生成器的 release_frame 记录各车释放边界。完成实验后，使用对应清单重算：

```powershell
python -m evaluation.summarize evaluation/outputs/<本次run_id> --spawn-manifest <本次spawn_manifest路径>
```

尖括号需要替换为实际路径。回放从最后一辆车释放后的下一帧开始，原始数据不修改，
并保存 replay_scope.json 及本次清单副本。没有完整释放记录或没有释放后帧时拒绝报告分析成功。
此边界对整个采集区生效，含背景车辆；新分析中的预热从重新观测开始，
边界前的到达不补造，进入区内的车辆可能左截断。清单必须来自同一场实验，地图和路口会校验。
