# 统一美化模板，再批量生产

本文件是下一阶段的实施方案。当前已完成道路标准化、单图生成与验证；资产目录、RoadRunner 批量美化器和 Unreal 打包器尚未实现。

## 1. 先完成一个可复用的标准场景

先以无路肩标准十字路口制作 urban_day_v1：统一沥青、路缘石、人行道、路灯、树木、建筑立面、标线和信号杆架。另用带路肩的 2×2 网格验证道路拼接及街区填充。小样须完整经过 RoadRunner → CARLA 对应 Unreal 工程 → 打包 → 干净 CARLA 实例加载；通过后冻结模板版本。

固定的交通层：三进三出、专用左直右、禁掉头、逐车道独立灯、停止线/斑马线及圆弧路缘。美化不能改变这些约束。树木不能挡灯，建筑不能侵入转弯包络，标线不能只是截图中好看。

## 2. 将模板拆为四层

| 层 | 保存内容 | 变化方式 |
|---|---|---|
| 道路标准 | road_standard.py 及规范版本 | 所有地图共用；修改时提升版本 |
| 美术主题 | 材质、色调、路缘/路灯/绿化/建筑资产白名单 | 按主题选择 urban_day_v1 等 |
| 布置规则 | 相对路缘的位置、间距、避让区、朝向和密度 | 根据道路/街区几何计算 |
| 地图实例 | 行列数、间距、路肩、主题版本、seed | 批量任务逐项指定 |

主题不保存某张地图的绝对 XYZ 坐标。路灯按道路里程和路缘偏移布置；建筑按街区边界和退界距离布置；转角使用道路圆弧计算。用独立 layout_seed / appearance_seed，避免换树木时连道路拓扑也变化。

## 3. 建立资产目录与可检查的规则

每个资产记录逻辑 ID、RoadRunner 本地引用、Unreal 资产引用、尺寸/包围盒、轴向/单位、材质、碰撞和语义类别、LOD 及来源。Git 保存引用和配置；CARLA/RoadRunner 附带模型与贴图仍由本机安装或授权资产库提供，不随工具代码复制。

首个主题建议仅使用少量经过验证的资产：一种沥青、两种人行道铺装、一种路缘石、一种路灯、2–3 种树和数种模块化建筑。资产少便于校准比例、碰撞与性能，后续增加主题不必重写道路生成器。

初始布置参数建议先在小样校准：路灯间距约 30m、树木间距约 8m、建筑距人行道外缘约 5m。它们是美化候选值，不是已确认道路规范或法规合规结论。斑马线/停止线区域、路口视距区、信号灯可见区域和车辆扫掠区必须显式设置为禁止放置区。

## 4. 采用 RoadRunner 模板项目并检查导入导出

模板项目保留主题资产映射、材质、坐标单位及导出设置。每张地图复制成独立场景，导入 XODR，应用同一套规则，再做少量人工检查。不要在一个人工美化完成的场景中反复替换道路，否则建筑/灯杆容易与新路网错位。

自动化程度取决于本机 RoadRunner R2024a 实际可用的 API、导入/导出选项和许可。先验证能否稳定复用资产映射与批量导出，再开发适配器；不能仅凭一份 JSON 假设 RoadRunner 会执行布置规则。无法自动化的步骤先明确记录人工检查点。

最终 FBX/材质与最终 XODR 必须来自同一版本场景。RoadRunner 若改写 road/lane/signal ID，重新生成运行 manifest 和控制器映射；不能沿用旧指纹强行通过加载检查。

## 5. 分两级验收后批量

模板级：完成 RoadRunner 往返、坐标/比例核对、交通灯触发与独立控制、车辆转向/净空、碰撞、材质/贴图、语义类别和 Unreal 打包加载检查。当前 debug 标线须替换为正式标线网格/贴花；当前运行时杆架须在关卡中持久保存。

实例级：每张生成地图检查道路连通、车道/灯映射、装饰越界和资产缺失；保存俯视/近景图、版本、seed、输入/输出哈希和报告。不同规模各做代表性的实机性能与车辆验证，不能用 1×1 通过推断 5×5 同样可用。

批次示例（实施建议，不是当前命令接口）：1×1、2×2、3×3、5×5 × 有/无路肩 × 3 个 appearance_seed。道路规模与主题通过显式任务清单组合，不默认遍历无限参数空间。

## 6. 建议的后续目录与开发顺序

```text
standardization/
  JunctionToolkit/             # 已实现的生成和验证
  maps/                       # 新生成地图，本工程内
  validation/                 # 已有验收实例与报告
  themes/urban_day_v1/         # 待实现：主题参数、资产目录、规则
  batches/                    # 待实现：批次任务清单
  roadrunner_templates/       # 待实现：本地模板项目，不提交商业资产
  exports/                    # 待实现：配套 XODR、模型与导出报告
  packages/                   # 待实现：CARLA cooked 交付包
```

推荐开发顺序：资产目录/布置规则定义 → 单图美化与打包闭环 → 主题版本冻结 → 批次生成与状态清单 → 批次验收。先完成可加载的小样，再自动放大产量。
