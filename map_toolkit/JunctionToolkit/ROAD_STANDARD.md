# 十字路口与规则网格统一规范

版本：urban_cross3_v1，2026-10-27。仅适用于新生成的十字路口和规则网格；不修改既有地图、实验记录或 profile。T 型和实验性环岛保留旧流程。

## 固定参数

- 每方向三进三出，单车道 3.5m，总行车宽度 21m，道路等级一致。
- 内侧仅左转，中间仅直行，外侧仅右转，禁止掉头。分别接入目标道路内侧、中间、外侧出口车道。
- 每条进口车道一个原生可控灯头；复用官方弧形悬臂杆架。每个十字路口 12 灯，不预设实验信号相位。
- 双黄实线每条宽 0.15m、净间距 0.15m；同向白虚线宽 0.15m、实段 3m、间隔 6m。进口停止线前 25m 改为白实线。
- 停止线宽 0.30m。斑马线位于停止线朝路口的一侧：停止线下游边缘至斑马线近端 1m；斑马线纵深 4m，跨越 21m 行车道，白条宽 0.5m、间隔 0.5m；远端距直路终点 2m。
- 路缘石宽 0.20m、高 0.15m，外接 2m 人行道。路口边界四个 12m 半径圆弧；XODR 圆弧路缘与直路边缘相切，铺面宽度采用圆弧采样逼近。
- 路肩默认关闭，开启后每侧增加 0.50m，位于行车道与路缘之间。
- 路口中心至直路端点距离自动计算为半幅车行道宽＋路肩宽＋12m：无路肩 22.5m，有路肩 23m。

## 可配置参数

行列数各 1–5；默认中心间距 350m、外围道路臂长 150m。间距和臂长允许覆盖，长度不是仅凭车型唯一推导的结果。地图名称、随机种子和路肩开关可配置。不能用宽度、车道数或转向参数绕过固定规范；冲突配置明确报错。

```powershell
# 从 JunctionToolkit 目录运行，输出目录必须为空
.\toolkit.cmd generate --config configs\cross3.json --out ..\maps\standard_cross3
.\toolkit.cmd generate --config configs\grid2x2.json --out ..\maps\standard_grid2x2
.\generate_map.cmd --type grid --rows 2 --columns 3 --name standard_grid_2x3 --shoulder
```

最小配置：

```json
{"name":"standard_grid","rows":2,"columns":2,"shoulder_enabled":false}
```

旧十字配置中的 junction_radius_m=22、roadside_props=true、非三车道或共享转向不符合新规范。建议从最小配置重新生成，或删除旧派生参数后检查；不静默改变用户传入的冲突参数。

## 导出与预览边界

道路连接、单双实线/虚线、路肩、抬高路缘和圆弧人行道写入 XODR。斑马线区域、白条和停止线轮廓作为 objects 导出，并以相同坐标绘制 CARLA 运行时预览。模型和控制器语义是否由 RoadRunner 保留，仍须在实际导入后检查。

当前 CARLA 预览的补充标线仍使用 debug 绘制，杆架仍是运行时放置的官方资产；不是已烘焙的 Unreal 地图包，也不是语义分割标注验收。路缘使用抬高的 sidewalk 几何，不附带单独的精细石材贴图。未生成行人导航数据或过街信号逻辑。

CARLA 0.9.15 对 sidewalk 网格使用约 0.1524m 的固定抬高；XODR 设计高度仍为 0.15m，实机高度检查允许这 2.4mm 的差异。铺面辅助道路使用非行车 shoulder 类型，防止引入虚假可驾驶路线；其车道段按圆弧采样拆分，规避 CARLA 直路仅采样段端点造成的缺口。

停止线是明确的地图设计边界，但尚不能当作已经校准的 Traffic Manager 自动停车边界。manifest 独立保存 signal_s 与 reference_s，信号灯位置不随停止线偏移。

## 验证

generate 后自动进行 CARLA 离线拓扑检查；标准地图还检查双黄线、进口实线段、斑马线/停止线间距、路肩/路缘尺寸、对象 ID 唯一性、圆弧端点与道路边界衔接，以及路口转弯车道两侧是否越过圆弧路缘。结果写入 topology_validation.json 的 standard_geometry。

离线几何检查不等于大型车辆扫掠包络、实车通行、碰撞或渲染认证。服务端检查及实际结果另见 STANDARD_VALIDATION.md。
